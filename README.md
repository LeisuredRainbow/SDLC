## Описание проекта: GitPulse

**GitPulse** — кроссплатформенная десктопная утилита, предназначенная для локального аудита Git-репозиториев и безопасной пакетной очистки сборочных артефактов (папок `bin`, `obj`, `node_modules`, `target` для языков C, C++, Java, C#, Node.js) с целью высвобождения дискового пространства.
